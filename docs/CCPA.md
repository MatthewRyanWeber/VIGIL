# CCPA Compliance Statement

**VIGIL Network Monitor** — Last updated: June 2, 2026

## Overview

The California Consumer Privacy Act (CCPA) grants California residents specific rights regarding their personal information. This document explains how VIGIL complies with CCPA.

## Applicability

**VIGIL does not collect personal information.** It is a local network monitoring tool that checks device availability (ping, HTTP, SSH, UDP). It processes network device IP addresses and hostnames — not personal information as defined by CCPA §1798.140(v).

## CCPA Rights

| CCPA Right | Status |
|------------|--------|
| **Right to Know** (§1798.100) | No personal information collected. Nothing to disclose. |
| **Right to Delete** (§1798.105) | No personal information stored. Device configs are local files you control. |
| **Right to Opt-Out of Sale** (§1798.120) | No data sold. No data collected. |
| **Right to Non-Discrimination** (§1798.125) | Not applicable. |
| **Right to Correct** (§1798.106) | No personal information held. |
| **Right to Limit Sensitive PI** (§1798.121) | No sensitive personal information collected. |

## Network Device Data

VIGIL stores IP addresses and hostnames of network devices you configure for monitoring. These are infrastructure identifiers, not personal information. They are stored locally on your machine and never transmitted externally.

If your monitoring configuration includes devices that could be linked to individuals (e.g., personal workstations with user-identifying hostnames), you are responsible for managing that data in accordance with CCPA.

## No Data Broker Activity

VIGIL does not sell, share, or transmit any data to third parties.
