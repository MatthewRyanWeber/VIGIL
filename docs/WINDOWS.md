# Vigil for Windows

Standalone Windows build of Vigil -- no Python installation required.

There are two ways to get it, both on the
[Releases](https://github.com/MatthewRyanWeber/VIGIL/releases) page:

| Download                        | What you get                                        |
|---------------------------------|-----------------------------------------------------|
| `Vigil-2.0-setup.exe`           | Installer, Start Menu entry, optional start-at-sign-in |
| `Vigil-2.0-windows-x64-app.zip` | The same app as a folder you can run in place        |

The installer is per-user: it installs to `%LOCALAPPDATA%\Programs\Vigil`, so
Windows never asks for administrator rights.

---

## Quick Start

1. Run `Vigil-2.0-setup.exe` (or unzip the portable build and run `Vigil.exe`)
2. Vigil starts in the system tray and opens `https://127.0.0.1:9443`
3. If the browser shows a certificate warning, click **Advanced** then
   **Proceed to 127.0.0.1**

That's it. Vigil is running.

---

## System Tray

Vigil lives in the notification area. The icon is an LED that matches the room
cards on the dashboard:

| Color  | Meaning                          |
|--------|----------------------------------|
| Blue   | No devices checked yet           |
| Green  | Every device is online           |
| Amber  | Some online, some offline        |
| Red    | Every device is offline          |
| Grey   | No devices configured            |

Hover for a count. Double-click to open the dashboard. Right-click for:

- **Open Vigil** -- opens the dashboard in Chrome or Edge
- **Start Vigil when I sign in** -- toggles a per-user login entry
  (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`); no admin rights, no
  scheduled task, and moving the install repoints it automatically
- **Quit Vigil** -- stops polling and exits

Closing the browser tab does not stop Vigil; use **Quit Vigil**.

## What gets installed

| File / Folder | Purpose                                                  |
|---------------|----------------------------------------------------------|
| `Vigil.exe`   | The application                                          |
| `_internal\`  | Bundled Python runtime and dependencies -- do not modify |
| `unins000.exe`| Uninstaller (installer builds only)                      |

These are created next to `Vigil.exe` on first run:

| File                      | Purpose                           |
|---------------------------|-----------------------------------|
| `config.json`             | Your rooms and devices            |
| `vigil-cert.pem`          | Self-signed HTTPS certificate     |
| `vigil-key.pem`           | Certificate private key           |
| `vigil.log`               | Rotating log file                 |
| `status.json`             | Device status cache               |
| `.vigil-trust-installed`  | Tracks whether cert was installed |

## Command-Line Options

Open a Command Prompt in the install folder and run:

```
Vigil.exe                     # Default: HTTPS on port 9443, runs in the tray
Vigil.exe --port 9000         # Custom port
Vigil.exe --host 0.0.0.0     # Allow LAN access
Vigil.exe --no-https          # Plain HTTP (not recommended)
Vigil.exe --no-browser        # Don't auto-open the browser
Vigil.exe --no-tray           # Foreground instead of the tray
```

## Moving your data

Your rooms and devices live in `config.json` beside `Vigil.exe`. Vigil rewrites
it the moment you change anything in Settings, and reads it back at startup.

Every install keeps its own copy, so a new install starts empty. To carry your
setup across -- from a portable copy to the installed app, or to another
machine:

- **Settings > Export** in the old copy, then **Settings > Import** in the new
  one. Import backs up whatever was there first, as `config.backup.json`.
- Or close both copies and copy `config.json` across by hand.

`status.json` holds the last known up/down state and is regenerated by the next
poll, so it is not worth copying.

## Firewall

Windows Defender Firewall may prompt you the first time you run Vigil. Click **Allow access** for private networks. If you plan to access Vigil from other machines on your LAN, make sure to allow it on the appropriate network type.

If you accidentally blocked it, open **Windows Defender Firewall > Allow an app through firewall** and enable Vigil.

## Troubleshooting

**"Windows protected your PC" (SmartScreen)**

This appears because the exe is not code-signed. Click **More info** then **Run anyway**.

**Browser says "This site can't be reached"**

Check the tray icon is still there -- if you quit Vigil, nothing is serving the page. Check that the URL is `https://127.0.0.1:9443` (https, not http).

**"Your connection is not private"**

Expected on first visit. Vigil uses a self-signed certificate. Click **Advanced** then **Proceed to 127.0.0.1**.

**Port 9443 is already in use**

```
Vigil.exe --port 9000
```

Then open `https://127.0.0.1:9000`.

**No tray icon appears**

Windows hides new tray icons by default. Click the **^** arrow next to the
clock, then drag Vigil onto the taskbar, or turn it on under **Settings >
Personalization > Taskbar > Other system tray icons**. Vigil is still running
either way -- the dashboard is reachable at `https://127.0.0.1:9443`.

**Devices show offline but are reachable**

1. Verify the IP address in device settings
2. Try switching from ping to UDP, SSH, or HTTP check type
3. Increase the device timeout
4. Check that Windows Firewall allows outbound ICMP

**Vigil is slow to start with many devices**

Vigil limits concurrent checks to 10 to avoid flooding the network. Rooms transition from blue to their final color as results arrive. The first full cycle may take a minute with many rooms.

## Updating

Run the newer `Vigil-2.0-setup.exe` over the top -- it replaces the program and
leaves `config.json` alone. For the portable build, replace everything except
`config.json`.

---

## Uninstalling

**Installed with the setup exe:** **Settings > Apps > Installed apps > Vigil >
Uninstall**. That removes the program, the shortcuts and the login entry, then
asks whether to delete your rooms and devices.

**Portable copy:** delete the folder. If you turned on *Start Vigil when I sign
in*, also clear the `Vigil` value under
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Vigil installs no
services and writes nothing else outside its own folder.
